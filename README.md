### 🔍 [Recon](https://github.com/7parth/Recon)
**Autonomous, human-supervised job application pipeline**

An 11-node LangGraph agent graph that reads your resume, searches for matching jobs, scores fit using a hybrid cosine+LLM scorer, tailors your resume and cover letter, then pauses for mandatory human review before submitting across 6 ATS platforms via Playwright automation.

**Key Engineering:**
- `interrupt_before` human review gate — the apply agent is hardcoded to never run without explicit approval
- Two-stage match scoring: embedding cosine similarity (floor filter) → LLM detailed analysis, blended 70/30
- `AsyncPostgresSaver` checkpointing — interrupted runs survive server restarts
- Opt-in Celery background workers with Redis, default path uses FastAPI `BackgroundTasks`
- SSE live log streaming for real-time pipeline visibility

`LangGraph` · `LangChain` · `FastAPI` · `Playwright` · `pgvector` · `Celery` · `Redis` · `Supabase` · `React 19`

### 🧠 [CiteMind](https://github.com/7parth/CiteMind)
**Production-grade citation-backed RAG system**

Hybrid retrieval pipeline combining PGVector cosine similarity and BM25, fused via Reciprocal Rank Fusion (RRF) with cross-encoder reranking. Every LLM response includes the source paper, page number, and exact excerpt — no hallucination without accountability.

**Key Engineering:**
- Hybrid retrieval: PGVector cosine + BM25 → RRF fusion → cross-encoder reranking
- NVIDIA NIM (`llama-3.3-70b-instruct`) for generation
- `BAAI/bge-base-en-v1.5` embeddings in Supabase pgvector for sub-second semantic search
- Ragas evaluation: faithfulness **0.92** · answer relevancy **0.88**

`FastAPI` · `LangChain` · `Next.js` · `NVIDIA NIM` · `Supabase` · `pgvector` · `Ragas`
